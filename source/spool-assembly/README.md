# Shared spool-holder installation

CORE One+ kit step9.3 uses six actions: align/lower the sheet, fit the O-ring,
align the holder, insert it and turn clockwise. Upgrade step2.7 uses the last
four on the detached right-panel workpiece. Both use the same whole-part
paths as initial preparation, in the shared installed CAD frame.

One complete25x3.5mm teaching O-ring is registered by the viewer before its
director is created. Maintenance reuses that owner. The installed Plus model
includes the ring; Original comparison excludes it. The panel pre-rotation
and rigid carry include the installed ring with its holder. Exploded offsets
also follow the holder. Source mesh positions, normals and indices remain
unchanged. The nominal quarter-turn is an illustration, not a stated torque.

Official sources: Prusa Research
https://help.prusa3d.com/guide/9-calibration-first-run_982308#999427
https://help.prusa3d.com/guide/2-printer-upgrade_1014628#1022776
Step/line IDs are retained in the plans; the upgrade has no sheet operation.
The preceding Puck fastening procedure is a separate programme.

Run node source/spool-assembly/build.mjs --out PATH_TO_CHECKOUT, optionally
with --check. The common projector reproduces the exact module/host fields.
Translations and their source recipe are in source/shared-spool-localization.
