# FE guide metadata and source phases

These editable data-only modules describe the protective-earth cable guide operations and their source-phase selection. The source contract distinguishes the saved CoreXY step key from the official guide anchor and compares complete typed plan metadata independently of translated labels.

The metadata composition extends only the five named build plans. Upgrade, completed-reference and before-comparison views retain their existing plans. Original and Gen2 procedures require their own source support. This module does not allocate geometry, create physical owners or acquire service leases.

Run `node source/fe-guide-sourcecarry/build.mjs OUTPUT_MODULE_DIRECTORY` to reproduce all nine JavaScript modules. The complete typed contract is an editable source file; a changed mechanical programme requires explicit contract review. Coordinates remain in the companion plan's declared units. These data modules do not establish fit, force or continuous clearance.

The official instruction references remain the CORE One+ kit manual, including preparation 986513, connection 986601, CoreXY source anchor 992683 and LCD connection 998504. Existing source photographs and instructions retain their separate rights.
