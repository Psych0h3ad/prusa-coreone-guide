Official step references

The ordered identifiers are factual references to the linked Prusa Research guides. The web sidebar counts its Begin assembly entry; printed instructions start with the first numbered instruction. Keep these ordinals separate. A site procedure may split one official step into several stages.

Edit guide-step-index.json and resolver-template.js, then run:
  node generate.mjs <output-directory>

This source contains no guide prose, photographs or manufacturer CAD. Original code and authored index arrangement: MIT; CORE One Community Guide contributors. Prusa materials retain their own terms. Full MIT text: ../../dist/licenses/maintenance-reference-MIT.txt.

Known PDF references use separately checked numbered headings and PDF page anchors. They are labelled as PDF steps, without the web start-card offset. Unknown or contradictory source references do not receive a guessed indexed number.
