CORE One ロッドホルダーの組み立て表示

Original CORE Oneの公式ガイド5.3、5.4、5.5、5.12、5.13、5.14、5.75に対応します。四つのホルダー、六本のM3×10、八本のM3×6、二本の325×10mmロッドを、既存の完全な形状で表示します。5.14では上側500/502だけを締めます。下側504/506は5.75まで緩めておき、Zスムースロッド313/369の上端を確認してから右、左の順で固定します。

公式ガイド:
https://help.prusa3d.com/guide/5-corexy-assembly_835522
部品は5.2、追加のM3×6とロッドは5.11に記載されています。5.10のリニアホルダーは仮置きです。後ホルダーの最終的なねじ頭は、5.12の全体写真と同じく左右とも外側へ向けます。左右の後ホルダーは同じ部品です。参照番号565と482を左、376と480を右の取付位置へ移し、形状や穴を変えずに組み合わせます。

取り回しの表示では、仮置きのリニアホルダー一式を手前へ寄せてロッドの入口を確保します。左後ホルダーは溶接端子を避ける向きで通します。その後ロッドを支え、仮締めの後ホルダーだけを一度端から抜き、プレート下で向きを戻して差し直します。この補助動作と移動量は元形状に基づく独自の取り回し例で、公式に指定された角度や距離ではありません。公式手順と写真の参照はsource moduleに保持しています。

長さの単位はmm、描画座標はmです。元のlocal形状、全表面、穴、ねじ、頭部、材質区分は変更しません。M3×10の長軸はlocalX、M3×6はlocalZです。前の上側2.75mm・下側1.5mm、後4.5mmの緩み量は、元形状の通し穴・tap・頭用の穴と周辺部品から求めた表示用の値です。下側も5.75まで締め切りません。実物の寸法測定やメーカーの回転数・トルク指定ではなく、整数回転は模式表示です。

段階ごとの緩め位置と後ホルダーの取付位置は、後の章を直接開いた場合も保持します。有限の姿勢での全表面確認は、連続動作全体、製造適合性、締結力を保証しません。元CADのねじ嵌合・円筒接触・取付面の正の接触記録は残しており、接触がすべてゼロという意味ではありません。

編集と生成:
original-rod-holder-data.js: 全部品の参照番号、頭側軸、寸法、緩め位置、取り回しのパラメータ。
original-rod-holder-source.js: 公式step・line・photo参照。
original-rod-holder-plan.js: 作業順、段階別位置、camera・focus。
original-rod-holder-scene.js: Original用の後ホルダー取付位置。
node source/original-rod-holders/build.mjs
で同梱の編集可能な四つのmoduleをdistへ生成します。dist/original/register.jsとdist/assembly-director.jsも編集可能なruntime sourceです。生成にCAD原本、アカウント、外部取得、非公開Git履歴は不要です。
