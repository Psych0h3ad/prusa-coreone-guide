# Filament maintenance

Step-by-step CORE One+ guides for checking the filament path, removing a broken piece and performing a manual cold pull. The displayed mechanism and material follow the selected step, including opening the idler, extracting material and reassembly.

Edit the modules under `runtime/`. Run `node build.mjs --out <checkout>` to reproduce the nine runtime modules; add `--check` to verify the output. Shared application bindings are maintained in `source/lcd-maintenance-route`.

Official instructions remain the source for temperatures, tools and work order. The model illustrates handling and does not simulate material melting or gripping force. See `SOURCES.json` and the adjacent license notices for source attribution.
